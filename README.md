A one-page newspaper front page that sums up the world news of Saturday 21 November 2026: Russian missiles landing in Poland and NATO calling it a grave violation, Wall Street sliding into correction as the AI sell-off deepens, Cyclone Akvan crossing the Odisha coast, Malaysia planning to resettle 10,000 Rohingya refugees after the ICJ genocide ruling, UK–EU deals in Brussels, and Trump returning from China after the first trilateral summit in Shenzhen.

The image is drawn at run time by `main.py` with the Python standard library only — no network, no randomness, no clock — so every run writes byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024×1024 PNG, under 1 MiB).
